# Tele Tinder Bot (aiogram 3)

## Local
1. `pip install -r requirements.txt`
2. `.env.example` -> `.env` (BOT_TOKEN, ADMIN_IDS, PAYMENT_PROVIDER_TOKEN)
3. `python bot.py`

## Render (Web Service)
Build: `pip install -r requirements.txt`  |  Start: `python bot.py`
Env: BOT_TOKEN, BOT_USERNAME, ADMIN_IDS, PAYMENT_PROVIDER_TOKEN, PYTHON_VERSION=3.12.7,
DATABASE_URL (PostgreSQL - permanent data), PRICE_SYMBOL, START_DELAY=20

## Admin (bot me hi)
/admin -> Stats, Users (list + detail), Find, Broadcast, Reports, Payments, History, CSV export
