# ConnectMate Discoverability / SEO

Telegram bots do not have website-style SEO. The practical growth setup is:

- Search-friendly bot name: ConnectMate — Dating, Match & Chat
- Short description with dating/match/nearby/chat keywords.
- Full description explaining Like, Skip, Match, private relay chat, posts and Premium.
- Referral deep links: `https://t.me/<BOT_USERNAME>?start=ref_<CODE>`.
- Public landing page/social profiles can link to the bot with UTM tracking.
- Keep username stable and promote one canonical link.
- Publish privacy/terms pages externally if collecting phone/social details.
- Use bot analytics/admin stats to measure `/start`, profile completion, matches, chats and paid conversion.

No SEO trick can guarantee Telegram search ranking; user retention, profile quality, safety and referrals matter most.
